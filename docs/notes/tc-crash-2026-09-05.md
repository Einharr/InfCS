# 5 Sep 2026: the client died at startup - the cause was the machine, not the build

The conclusion after six attempts: **the system had no active mouse at all**, and
the client dies while initializing DirectInput. The QoL update from Infinity
(`dinput8.dll`, TC manifest `2026-09-05T02-01-38Z`) had nothing to do with it -
the first version of this document blamed it wrongly.

## The symptom

A crash about 10 s after startup, before the UI loads. With QoL's default settings
it writes `(null)-stage.119798-<time>.txt` with no minidump (the crash happens
inside the client's own crash handler, offset `0x0069f7c3`). With
`chatEnterGuard=0` in `infinity_qol.ini` the dump comes out properly:

```
swgemu.exe: stage.119798
unknown location : FATAL d716648f: failed to create DirectInput device (340)
```

340 = 0x0154 - the low word of `REGDB_E_CLASSNOTREG` (0x80040154).

## The proof

`harness/ditest.py` through the system `dinput8.dll` (not through the QoL proxy):

```
DirectInput8Create           hr=0x00000000
CreateDevice keyboard        hr=0x00000000
CreateDevice mouse           0x80040154 "Class not registered"
```

`Get-PnpDevice -Class Mouse`: four "HID-compliant mouse" entries (Logitech over
Bluetooth LE), all with status Unknown - not connected. `-PresentOnly` for the
Mouse and Keyboard classes is empty. The parents, "Bluetooth Low Energy GATT
compliant HID device" (MX Master 3S, MX Keys), are present - the devices are
asleep. Access to the machine goes through AnyDesk, which types via SendInput and
creates no HID devices. DirectInput creates a keyboard even with no device, but
not a mouse.

What had been tried before that (all of it crashed identically): with our files
and without, with the virtual pad and without, with the runtime patch and without,
`useJoysticks=0`.

## What to do before a rig session

1. Wake up or connect a mouse (the MX Master 3S) - or plug a DualSense in over
   USB: its touchpad shows up as a HID mouse. The check:
   `python harness\ditest.py` -> `CreateDevice mouse hr=0x00000000`.
2. Close Steam (it grabs the PS button and substitutes the pad profile).
3. Then follow the current order: `patch_joy.py` -> launcher Play -> `inject.py`
   (see [`../04-run-and-build.md`](../04-run-and-build.md)).

An incidental finding for Infinity: with `chatEnterGuard=1` (the new QoL build) no
dump is written for a fatal error at startup - what is left is a `(null)-stage...`
file with no minidump and no error text; with `chatEnterGuard=0` the dump is
normal.
