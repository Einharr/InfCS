# Screenshots from the live client

Test Center, a real DualSense through `harness/inject.py`. The debug panel in the
corner of some of the shots is the rig's own (`consoleport.ini`, `debug=1`), not
part of the interface.

| Shot | What is in it |
|---|---|
| [`01-game-menu-radial.webp`](01-game-menu-radial.webp) | Mos Eisley outskirts: the game menu radial on the stick - Map, Journal, Inventory, Datapad, Character, Skills, Mail, Options, Community, Commands, Service. Above it the crossbar diamonds on the stock toolbar; the panel on the left is the rig's state line |
| [`02-target-ring.webp`](02-target-ring.webp) | the target ring: three worrts at 88, 94 and 95 m placed around the player by bearing, the ring red because the context is foes, the hints `Target` / `Cancel` under the pane |
| [`03-hints-cycle-allies.png`](03-hints-cycle-allies.png) | the hint panes for cycling: `LB Prev ALLY` / `RB Next ALLY`, and on a hold `LB Hold Party` / `RB Hold Targets`. RT switches the set |
| [`04-mission-browser.png`](04-mission-browser.png) | the stock Mission Browser driven from the pad: the Destroy list, the row focus on the first mission |
| [`05-object-cycle-terminal.webp`](05-object-cycle-terminal.webp) | cycling world objects: the Mission Terminal picked out with the arrow markers, the hints green because the context is objects - `Radial`, `Use`, `Clear` |
| [`06-inventory-context-radial.png`](06-inventory-context-radial.png) | the radial context menu on an inventory item: `1) Unequip`, `2) Examine`, `3) Destroy` - the client's own menu, read off the item and laid out on the ring |
| [`07-on-screen-keyboard.webp`](07-on-screen-keyboard.webp) | the on-screen keyboard over the chat line, the hint row `Type / Back / Space / Send / Move / Shift / Symbols / Close`; the state line shows `pad mode keyboard 1.0` |
